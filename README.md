# Products Lab

**Продуктовая лаборатория Ростелеком × ВУЗы**

Платформа для трансфера продуктовых гипотез из Ростелекома в университеты. Студенты получают реальные бизнес-задачи и создают работающие прототипы на хакатонах и практиках.

## 🚀 Демо

[products-lab.github.io](https://mdyuzhev.github.io/products_lab/)

## 🎯 О проекте

Products Lab — это программа сотрудничества между Ростелекомом и ведущими университетами России:
- **Сириус** — хакатоны и образовательные интенсивы
- **СПбПУ Политех** — практики, ВКР, курсовые проекты

### Как это работает

1. **Гипотеза** — Ростелеком формулирует продуктовую гипотезу
2. **Команда** — формируется студенческая команда с ментором
3. **Разработка** — исследование, проектирование, MVP
4. **Защита** — презентация экспертам с демо
5. **Результат** — внедрение, стажировки, рекомендации

## 🛠 Технологии

- **React 18** + Vite
- **Tailwind CSS** — стилизация
- **Framer Motion** — анимации
- **Lenis** — плавная прокрутка
- **Lucide React** — иконки

## 📦 Установка

```bash
# Клонирование репозитория
git clone https://github.com/Mdyuzhev/products_lab.git
cd products_lab

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build
```

## 🌐 Деплой

Проект автоматически деплоится на GitHub Pages при пуше в `main` ветку через GitHub Actions.
